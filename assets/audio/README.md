# Áudio do Catris

O jogo usa **Web Audio API** com tons gerados em tempo real (não requer ficheiros nesta pasta).

Para substituir por ficheiros reais, adicione aqui e estenda `js/audio.js`:

- `bgm.ogg` — música de fundo em loop
- `line-clear.ogg`, `level-up.ogg`, `lock.ogg`, `game-over.ogg` — efeitos

Sprites PNG opcionais para gatos: `../cats/cat-i.png` … `cat-l.png`
